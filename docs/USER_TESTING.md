# User testing

No external user testing has been run on this build. This file is the protocol and a results table to complete. Do not present the template as evidence.

## Protocol (5 participants: 2 creators, 1 agency writer, 1 manager, 1 legal reviewer; 20 minutes each)

Tasks: (1) fix the Winter social post until it can be submitted; (2) explain in your own words why the savings finding appeared; (3) as manager, approve the newsletter; (4) as reviewer, decide whether to waive the competitor finding; (5) find which guideline writers struggle with.

Measure: task completion, time, where they hesitated, whether they trusted suggestions, SUS score (10 questions).
